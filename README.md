# CrossLangWord — Support

The support and help page for
[CrossLangWord](https://github.com/NextGenPowerToys/crosslangword), published
for the App Store and Google Play listings.

**Live page: https://nextgenpowertoys.github.io/grosslangword-support/**

That Pages URL — not this repository URL — is what belongs in the store
listings.

## Editing

`index.html` is the whole page; `style.css` is shared with the privacy site.
Pushing to `main` republishes within a minute or so.

## Keep it current

The page names things that change release to release — the shipping languages
(English, Russian, Hebrew, Italian), the topic count (15), the grid sizes, and
the contact address. Revisit it whenever a language or feature lands.
